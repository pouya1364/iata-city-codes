# Data Sources

This package's data is generated by [`scripts/build-data.ts`](scripts/build-data.ts). Do not hand-edit `src/data/*.json` — re-run `npm run build:data` instead.

Last generated: **2026-08-14**

## Primary source

**[lxndrblz/Airports](https://github.com/lxndrblz/Airports)** (MIT-licensed community dataset)

- `airports.csv` — one row per airport, including its IATA code, ICAO code, name, `city_code` (the grouping metro-area code), country, and a `type` field (`AP` = airport, `CC` = pure city code with no coinciding airport). Fetched from `https://raw.githubusercontent.com/lxndrblz/Airports/main/airports.csv`.
- `citycodes.csv` — metadata (display name, country) for city/metro-area codes. Fetched from `https://raw.githubusercontent.com/lxndrblz/Airports/main/citycodes.csv`.

`airports.generated.ts` is built from every `AP`-type row in `airports.csv`. `cities.generated.ts` groups those airports by `city_code`, using `citycodes.csv` for the city's display name and country where available (falling back to the sole airport's own name/country for single-airport codes not listed in `citycodes.csv`).

## Cross-check source

**[Wikipedia: List of cities with more than one commercial airport](https://en.wikipedia.org/wiki/List_of_cities_with_more_than_one_commercial_airport)**

The build script fetches this page and flags (via `console.warn`, non-fatal) any city name it can extract that doesn't appear in our multi-airport grouping, so gaps can be manually reviewed. This is a heuristic text match, not a full HTML table parse — expect some false positives (e.g. individual airport names on the page matching nothing), which is fine since the check is advisory only.

## Manual overrides (not derivable from source data alone)

Encoded in `CITY_CODE_OVERRIDES` / `AIRPORT_NOTES` in `scripts/build-data.ts`:

- **BWI → WAS**: the upstream CSV only maps `DCA` and `IAD` to the `WAS` (Washington, D.C.) city code; `BWI` is commonly grouped under `WAS` too (per [Wikivoyage: Metropolitan area airport codes](https://en.wikivoyage.org/wiki/Metropolitan_area_airport_codes)), so it's added manually.
- **EAP / BSL / MLH notes**: the upstream CSV already correctly groups all three under city code `EAP`, but the relationship (one physical airport, three codes — Swiss side `BSL`, French side `MLH`, binational `EAP`) is non-obvious, so each airport record gets an explanatory `notes` field.

No other manual data edits were made. Legacy/renamed-city aliases (e.g. Beijing formerly Peking) were checked for on Wikivoyage during the build but none were found beyond what upstream already encodes, so none are fabricated here.

## Not the official source

This is **not** IATA's official City Code Directory. That is a paid product — see [IATA's Airport Codes page](https://www.iata.org/en/publications/directories/code-search/) for the authoritative, guaranteed-current source.
